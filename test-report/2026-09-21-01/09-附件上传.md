# 09 · 附件上传线(L9)

- 业务线:Composer 附件入口 → 上传 → chip 渲染 → 消息携带 → resourceUrl 读回;超限与不支持类型
- spec:`e2e/specs/10-attachments.spec.ts`(3 用例,3 通过)
- 前置:V7 迁移已给演示模型 mock-text 配多模态能力(`image/file` × `url/base64` 双传输);服务端约束:base64 ≤10MB、url ≤20MB、Spring multipart 20MB。

## L9-01 · 附件上传 → chip 渲染 → 消息携带 → resourceUrl 读回

- 步骤:合法 1x1 PNG 经附件入口 `setInputFiles` 上传;断言附件条(`assistant-attachments`)出现、文件名可见、缩略图 `<img>` 真实加载(naturalWidth>0);psql 核对登记行;携带附件发送消息至终态;`GET {API根}{resourceUrl}` 读回(本用户/他人);越权读回断言。
- 期望:上传成功、chip 含缩略图+文件名、resourceUrl=`/attachments/{id}`(API 根相对)可读回、他人 404 不泄露存在性。
- 实际:全部符合 —— 登记行 `mime=image/png, input=image, transport=base64`(≤10MB 走 base64);读回 200 + `image/png` + 字节一致;他人读回 404。**实际与预期的偏差**:消息发出后,消息区(用户气泡/时间线)**不渲染任何附件缩略图或文件名**(仅文本),与「消息携带附件渲染(缩略图/文件名)」预期不符 → 记录观察项 F14。
- 判定:✅ 通过(上传/读回/越权全链路正常;附件在消息区不渲染记 F14)
- 证据:`L9-02-附件chip(缩略图+文件名).png`、`L9-03-psql-附件登记行.txt`、`L9-04-消息完成后-消息区附件渲染观察.png`、`L9-04-消息区附件渲染观察.json`(attachmentRenderedInMessages=false, messageImages=0)、`L9-05-resourceUrl读回-headers.txt`、`L9-06-越权读回-响应.txt`

## L9-07 · 超限文件:>10MB 走 url 回退(设计内),>20MB 服务端拒收 → UI 反馈

- 步骤:①15MB PNG(>10MB base64 上限):mock-text 具备 url 传输 → SDK 传输回退;②25MB PNG(>服务端 multipart 20MB):期望明确错误反馈。
- 实际:①15MB 上传成功(transport=url 回退,UI 无错误,chip 正常)—— 属 SDK assistantMultimodal 设计内行为;②25MB 被服务端拒收,UI 输入区错误条可见,但文案为**「服务器内部错误」**(Spring multipart 超限 `MaxUploadSizeExceededException` 未映射业务异常 → 500),不是可读的 413/400 提示 → 记录观察项 F15;25MB 附件未被加入。
- 判定:✅ 通过(两类边界均有明确可观察结果;文案问题记 F15)
- 证据:`L9-08-15MB文件-传输回退观察.png`、`L9-08-15MB传输回退.json`、`L9-09-25MB超限-UI错误反馈.png`、`L9-09-25MB错误反馈文案.txt`

## L9-10 · 不支持的媒体类型 → UI 错误反馈

- 步骤:上传 `.exe` 文件。
- 期望:客户端拦截并给出可读反馈,附件不加入。
- 实际:输入区错误条精确提示「e2e-l9-evil-*.exe 不是支持的图片、视频、音频、PDF 或文本文件」,附件未加入;未发起网络上传。
- 判定:✅ 通过
- 证据:`L9-10-不支持类型-UI错误反馈.png`、`L9-10-不支持类型反馈文案.txt`

## 本线结论

| # | 用例 | 判定 |
| --- | --- | --- |
| L9-01 | 上传/chip/消息携带/resourceUrl/越权 | ✅(F14:消息区不渲染附件) |
| L9-07 | >10MB url 回退 / >20MB 拒收 | ✅(F15:500 文案) |
| L9-10 | 不支持类型拦截 | ✅ |

- 测试口径说明:在补偿代理页执行(DEMO-host 处 DEF-05 使上传 URL 双重前缀 404,见 07 分册)。
- 修复意见(F14):用户消息携带附件时,应在用户气泡/时间线渲染附件卡(缩略图/文件名,resourceUrl 经 `resolveMediaUrl` 拼接);历史回放路径同。
- 修复意见(F15):为 `MaxUploadSizeExceededException` 映射 413/400 + 可读文案(「附件大小不能超过 20MB」),与 `AgentAttachmentService` 的 400 语义对齐。
- 修复意见(F16,记录):>10MB 且模型具备 url 传输时静默回退 url(≤20MB 可传),UI 无任何提示;「url 传输要求公开可访问存储」的契约在本地演示环境的语义建议在文档中澄清。
