## A. 界面人性化(让人「一看就会、一用就顺」)

### A1. 对话空态给「开场引导 + 一键问题chip」 — P1/M
- **现状**:WC 聊天主区空态是整片空白(证据:`assets/L4-1-mounted.png`);新用户不知道该说什么,确认流这类核心剧本必须照画廊「剧本折叠」手抄提示词,措辞稍有偏差模型还会先反问澄清(本轮 L5-1 即因此 120s 未达确认卡)。
- **对标**:Intercom/Fin 空态给 3-5 个建议问题 chip;飞书助手按场景给「你可以试试」。
- **建议**:空态按 agentType 渲染该场景「剧本第一条」作为可点击 chip,点击即预填输入框;确认流场景额外给一条「演示确认卡」chip,文案用实测能稳定触发工具调用的句式。

### A2. 会话列表按场景隔离、可批量清理,主区给「新会话」入口 — P1/S
- **现状**:侧栏会话列表混排所有历史(测试截图里同屏出现「10 小时前」「17 小时前」的旧探针会话),新会话按钮藏在折叠侧栏顶部;长时间演示会越积越乱。
- **对标**:ChatGPT/Claude 侧栏按时间分组 + 顶栏常驻「新会话」;飞书助手按智能体隔离会话。
- **建议**:①会话按当前 agentType 过滤分组;②主区头部常驻「新会话」按钮;③提供「清空演示数据」一键(演示环境刚需,防现场翻出历史杂音)。

### A3. 回复气泡补齐「复制 / 重新生成」与流式光标 — P1/S
- **现状**:回复为纯 markdown 渲染,无复制/重答操作,流式期间无打字指示(证据:`assets/L4-2-sse-reply.png`)。
- **对标**:所有主流 AI 工作台的标配(Intercom Fin、Notion AI、飞书 AI 均有 copy/regenerate)。
- **建议**:气泡 hover 出现「复制/重新生成」;流式期间尾部渲染光标动画;错误中断时给「重试」按钮而非纯文本。

### A4. 登录页:行内校验 + 记住上次用户名 — P2/S
- **现状**:空用户名点击「登 录」仅被静默拦截(证据:`assets/L1-1-empty-blocked.png`,无行内错误文案);不记住上次演示账号。
- **对标**:成熟产品登录错误一律行内化(Element Plus rules 触发 blur 已具备,只差必填提示文案配置);GitHub/Vercel 登录页记住用户名。
- **建议**:必填规则加 message(「请输入演示账号」);登录成功后 localStorage 记住用户名做默认值。

## B. 功能合理化(让演示「讲得通、跑得稳」)

### B1. 确认流剧本的「确定性」保障 — P0/配套 DEF-02
- **现状**:确认流的触发依赖模型自由发挥,模型可能先反问澄清(本轮实测),工具面缺陷(DEF-02)又使其必然失败;演示现场不可复现。
- **对标**:产品演示的黄金路径应当「一键可复现」(Stripe Docs 的可运行示例、Vercel 的 Demo 按钮标准)。
- **建议**:①修复 DEF-02 后,把画廊「剧本」升级为「一键演示」:点击直接深链+自动预填+自动发送;②服务端为确认流提供 dry-run 断言(工具面非空);③剧本提示词按本轮实测收敛句式改写,减少模型澄清概率。

### B2. 工具演示页补「渠道过滤 + 事件流自动刷新开关」 — P1/S
- **现状**:工单列表 channel=agent/direct 仅以标签区分,无过滤;事件流无自动刷新开关(证据:`assets/L9-1-direct-ticket.png`、`L9-2-webhook-events.png`)。
- **对标**:AWS 控制台资源列表的过滤 tab + 自动刷新开关;Stripe 事件流的 live toggle。
- **建议**:加「全部/Agent 创建/表单直建」过滤 tab;事件流加「自动刷新(5s)/暂停」开关与新事件高亮;工单行加「查看关联运行」深链。

### B3. 工单 SLA 承诺在 UI 兑现 — P2/M
- **现状**:系统提示词向用户承诺 SLA(high 30 分钟响应…),但工单列表不展示任何 SLA/时限信息,承诺无处核实。
- **对标**:Jira/Zendesk 的 SLA 列与倒计时是客服台标配。
- **建议**:工单行增加「响应时限」列(按优先级换算),临期高亮;演示叙事上把「承诺→可见」闭环做实。

### B4. 总览页状态卡可观测性 — P1/S(配套 DEF-01)
- **现状**:状态自检 fail-open,但徽标缺失(DEF-01)、无检测时间、无手动重查;用户无法判断数据新鲜度。
- **对标**:Vercel/AWS 状态卡的 "Last checked 12s ago · Refresh"。
- **建议**:DEF-01 修复后,徽标旁加相对时间(IaTime 已有组件)+ 刷新按钮;连续失败时徽标转黄并列出首次失败时间。
