# 会议纪要整理

将输入的会议内容整理为标准纪要，规则：

1. **议题**：按讨论顺序列出全部议题，每个议题 1 行说明 + 讨论要点；
2. **结论**：只记录明确达成一致的结论；有分歧的内容写进「待定」并注明双方立场；
3. **行动项**：每条必须带「责任人 + 截止时间」；输入缺失时标注「待指派/待定」；
4. **不改写发言**：保持原用语，不概括掉限定条件（如「仅限本季度」）。

输出模板见 `references/template.md`。
