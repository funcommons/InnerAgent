# 快速开始 · 01 五分钟跑起来

> 目标:本机拉起整套依赖 + InnerAgent server + 平台前端,完成第一轮 Agent 对话。

## 前置

| 依赖 | 版本 | 用途 |
| --- | --- | --- |
| Docker(含 compose) | 近两年版本均可 | PG/Redis |
| JDK | 21 | server |
| Maven | 3.9+ | 构建 |
| Node + pnpm | 20.19+/22.12+,pnpm 9+ | 平台前端(可选,API 联调可跳过) |

## 1. 起依赖服务(1 分钟)

```bash
docker compose -f docker/dev-compose.yml -f scripts/dev-compose.e2e-ports.yml up -d
# PG :35432 / Redis :36379
```

> `docker/dev-compose.yml` 单独使用时宿主端口是 **15432/16379**(避让常见占用);
> 叠加 `scripts/dev-compose.e2e-ports.yml` 覆盖层才映射到本手册统一口径的 35432/36379。
> 端口仍被占用时改覆盖层映射,并同步下文 `IA_REDIS_PORT`。

## 2. 构建 + 启动 server(2 分钟)

```bash
cd inneragent-server
mvn -DskipTests package

IA_ADMIN_KEY=test-key \
IA_REDIS_PORT=36379 \
IA_CORS_ALLOWED_ORIGINS=http://localhost:9203,http://localhost:18081 \
java -jar target/inneragent-server-0.1.0-SNAPSHOT.jar
```

| 环境变量 | 说明 |
| --- | --- |
| `IA_ADMIN_KEY` | 管理面密钥,所有 `/ia/api/v1/admin/*` 请求头 `X-IA-Admin-Key` |
| `IA_REDIS_PORT` | Redis 端口(与 compose 对齐) |
| `IA_CORS_ALLOWED_ORIGINS` | 允许跨域的前端来源(逗号分隔) |

首次启动会引导创建管理员账号(交互式;本地联调可用 `admin`/`Admin#12345` 口径)。

健康检查:

```bash
curl -s http://localhost:18090/actuator/health
# {"status":"UP",...}
```

## 3. 发起第一轮运行(1 分钟)

本地 `local` profile 支持匿名演示头,免 token 直接体验:

```bash
curl -N -X POST http://localhost:18090/ia/api/v1/runs \
  -H 'Content-Type: application/json' \
  -H 'X-IA-Demo-User: 12993' \
  -d '{"conversationId":null,"message":"现在几点了?","agentType":"demo","toolExecutionMode":"DEFAULT","enabledSkills":[]}'
```

你会看到 SSE 流(text/event-stream),形如:

```
id: <runId>:1
event: pipeline-event
data: {"outputType":"RUN_STARTED",...}

id: <runId>:2
data: {"outputType":"CONTENT","content":"现在时间是...","createdAt":...}

id: <runId>:N
data: {"outputType":"DONE","usage":{...}}
```

要点:

- `id` 格式 `<runId>:<seq>` —— 断线后拿最后一帧 id 作 `Last-Event-ID` 即可续传;
- `demo` Agent 内置工具(如 `get_current_time`),`DEFAULT` 模式读工具自动放行;
- 把 `toolExecutionMode` 换成 `ALWAYS_ASK` 重发一次:工具调用会先推
  **确认卡事件**(`USER_CONFIRM_REQUIRED`),运行进入 `WAITING_CONFIRMATION`,
  SSE 保持打开等你确认 —— 这就是平台的强制授权语义。

## 4. 起平台前端(可选,1 分钟)

```bash
cd web && pnpm install && pnpm build
# 网关方式(静态资源 + /ia 反代):
node e2e/gateway.mjs        # http://localhost:18081
```

或直接开发模式(9203,需 server CORS 已含该来源)。用管理员账号登录后即可在
控制台看到会话/运行/事件流与指标大盘。
