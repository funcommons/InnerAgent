# 技术白皮书 · 01 产品概述

> 读者:评估是否接入本平台的业务/技术决策者与架构师。10 分钟。

## 1. 一句话定位

**InnerAgent 是可私有化部署的多租户 Agent 中台**:把「让业务系统拥有一个会用工具、
守授权、可观测的 AI 助手」所需的全部平台能力产品化,宿主应用以"注册工具 + 签发身份 +
挂组件"三步接入。

## 2. 解决什么问题

业务团队自研 Agent 通常会遇到四类成本,本平台逐一对位:

| 自研痛点 | 平台对位能力 |
| --- | --- |
| Agent 编排/流式/重连等基础设施重复造轮子 | 运行引擎 + SSE 事件流(`Last-Event-ID` 断点续传)+ 会话/消息持久化 |
| **工具调用越权风险不可控** | 平台级授权策略:所有工具调用经策略裁决;`DEFAULT` 下 WRITE 级强制用户确认、`ALWAYS_ASK` 下全部确认且授权不可绕过(另有 `ALWAYS_ALLOW`/`FULL_ACCESS` 显式豁免档,见 [05-最佳实践/01](../05-最佳实践/01-工具授权与确认流.md));宿主工具以内环 act token(60s)受限回调 |
| 模型绑定/切换成本 | 模型登记制(`ia_ai_model`):按类型设默认、排序即优先级、按应用全局可见;支持 mock 模型做确定性测试/压测 |
| 出问题黑盒 | 全链路事件 journal(可回放)、`/actuator/prometheus` 业务指标(运行/事件/重连/确认)、Webhook 事件订阅 |

## 3. 核心能力清单

1. **Agent 运行引擎**:一轮对话 = 一次运行(run),全生命周期状态机
   (`RUNNING → WAITING_CONFIRMATION → COMPLETED/FAILED/CANCELLED`;SSE 侧终态事件
   对应 `DONE/ERROR/CANCELLED`),持久化可回放。
2. **工具体系**(三种来源,统一 FQN 命名空间 `mcp__<serverKey>__<tool>`):
   - **宿主桥工具**:宿主后端用 `@IaTool` 注解暴露业务方法,starter 自动装配 MCP 端点
     (`/ia-mcp`),按 `riskLevel=READ/WRITE` 分级授权;
   - **三方 MCP 服务器**:应用级(管理面登记)与用户级(用户自助)两种注册,支持
     streamable-http 传输 + STATIC_HEADER 鉴权(OAUTH 为枚举预留位);
   - **平台内置工具**(如时间、知识库检索)。
3. **授权确认流**:工具调用按策略可能转入 `WAITING_CONFIRMATION`,向用户推确认卡;
   超时(默认 24h)自动过期。`DEFAULT`/`ALWAYS_ASK` 档该语义对宿主透明且不可绕过;
   `ALWAYS_ALLOW`/`FULL_ACCESS` 为显式豁免档(批量自动化用,须由调用方在请求体主动选择)。
4. **模型接入**:OpenAI 兼容协议为主;内置 **canned mock 模型**(规则脚本确定性出字),
   支撑 CI 回归与容量压测不耗真实 token。
5. **前端接入**:Web Component `<inneragent-chat>`(sdk-js:core+components)直挂,或
   iframe + postMessage 模式(token 不入 URL)。
6. **观测与治理**:Prometheus 指标(IA-1/IA-5 系列)、工具审计日志、多租户(appId)
   行级隔离。

## 4. 与"直接调大模型 API"的边界

| 维度 | 裸大模型 API | InnerAgent |
| --- | --- | --- |
| 工具调用 | 自己实现 function-calling 循环 | 平台编排 + 授权策略 + 审计 |
| 多用户/多应用隔离 | 自建 | 租户/应用/用户三级行级隔离 |
| 前端流式体验 | 自建 SSE/重连 | 事件流 + 断点续传 + 现成组件 |
| 合规审计 | 无 | 工具调用全审计,凭据不落审计 |
| 换模型 | 改代码 | 管理面登记/切换,应用无感 |

**不适合的场景**:需要单机嵌入式运行(本平台为独立服务形态)、强离线环境。

## 5. 价值小结(给决策者)

- 接入成本:宿主侧 **1 个 starter 依赖 + N 个 @IaTool 方法 + 1 个组件标签**;
  参考实现 `examples/acme-demo` 前后端合计千余行,即完整接入口径。
- 安全模型:私钥不出宿主后端;运行期平台持公钥验签;工具回调走 60 秒短时 act token;
  默认档位下用户确认语义平台强制(豁免档须显式声明,详见最佳实践 01)。
- 可演进:从单应用试点(一个 appKey)到多应用/多模型/三方 MCP 生态,不需要改接入方式。
