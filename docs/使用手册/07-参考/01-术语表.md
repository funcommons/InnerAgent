# 参考 · 01 术语表

> 按主题分组;「代码位」给出仓内权威出处,便于深入。

## 角色与租户模型

| 术语 | 含义 | 代码位 |
| --- | --- | --- |
| 平台方 | 运营 InnerAgent server 的一方,持有管理面密钥 | — |
| 接入方/宿主 | 把 Agent 能力嵌入自己应用的业务系统(=本手册读者) | examples/acme-demo |
| 租户(tenant) | 平台级隔离单元;平台级表(如 `ia_ai_model`)不受租户注入 | 平台 TenantContext |
| 应用(appId/appKey) | 接入方在管理面登记的接入主体,行级隔离的边界 | `/ia/api/v1/admin/apps` |
| 终端用户(userId) | 宿主的登录用户;embed token claims 的 `sub`,平台侧行级隔离键 | EmbedTokenSigner |

## 运行与对话

| 术语 | 含义 | 代码位 |
| --- | --- | --- |
| 会话(conversation) | 一段多轮对话的容器;`conversationId` 为空则新建 | `AiChatReqVO` |
| 运行(run) | 一轮请求的执行单元,状态机 `RUNNING → WAITING_CONFIRMATION → COMPLETED/FAILED/CANCELLED` | `AgentRunStatus` |
| 事件 journal | 事件持久层(`ia_agent_event`),事实源,可回放;≈11 条/运行 | AppendTx 写入 |
| 投影(ia_agent_message) | 面向展示的消息表(≈2 条/运行:user+assistant) | AgentMessageProjectionService |
| SSE 事件帧 | `id: "<runId>:<seq>"` + `data: AiChatStreamRespVO JSON`;终态事件 `DONE/ERROR/CANCELLED` | AiPipelineController.toSse |
| 断点续传 | `GET /runs/{runId}/events` + `Last-Event-ID`(或 `afterSequence`),replay-then-live | AgentRunReplayService |
| 首字(全含/不含模型) | 首 CONTENT 事件延迟;「不含模型」= 全含 − 首条 CONTENT 自带 `reasoningDurationMs` | tools/k6/lib/metrics.js 头注 |

## 工具与授权

| 术语 | 含义 | 代码位 |
| --- | --- | --- |
| 工具 FQN | 工具箱内唯一名 `mcp__<serverKey>__<tool>`,防跨源重名遮蔽 | ToolRegistryService.fqnOf |
| 宿主桥(/ia-mcp) | 宿主后端由 starter 装配的 MCP 端点;`@IaTool` 方法自动暴露 | inneragent-starter |
| 风险分级 | `READ`(DEFAULT 档自动放行)/`WRITE`(默认强制确认;@IaTool 缺省 WRITE) | ToolRiskLevel |
| toolExecutionMode | `DEFAULT`/`ALWAYS_ASK`/`ALWAYS_ALLOW`/`FULL_ACCESS`(后两档为显式豁免,须调用方主动声明) | AgentToolPermissionPolicy |
| 确认流(WAITING_CONFIRMATION) | 工具调用挂起等用户确认;确认卡事件 `USER_CONFIRMATION_REQUIRED`;超时默认 24h 自动过期 | ToolConfirmation* |
| 审计 | 工具决策落审计(decision/decisionSource/toolFqn),**不含凭据** | ToolAuditService |

## 身份与安全

| 术语 | 含义 | 代码位 |
| --- | --- | --- |
| embed token | 宿主后端 RSA(RS256)签发的用户身份令牌,前端持其调平台;私钥不出宿主 | EmbedTokenSigner |
| act token | 平台回调宿主桥的短时凭证(`X-IA-Act`,60s,受众限定 act.audiences) | starter 自动装配 |
| webhook | 平台向宿主推送事件;HMAC 验签三原则(原始字节/常量时间/快回 2xx) | IaWebhookVerifier |
| SSRF 护栏 | 用户自助登记三方 MCP 拒绝本机/内网地址(应用级管理面不受限) | McpUserServerService |

## 平台机制

| 术语 | 含义 | 代码位 |
| --- | --- | --- |
| outbox | 事件 journal → Redis 唤醒提示的跨实例扇出桥(500ms×200 行/批,已批量化 ~400 行/s) | AgentEventOutboxPublisher |
| keep-alive | SSE 30s 一条注释行,暴露死连接使流/循环/订阅及时释放 | AiPipelineController.withKeepAlive |
| mock 模型(规则式) | `ia_ai_model.config.mockScript`:`rules[{match/tool/args/reply}]+default+deltaMs`;`$1..$9` 捕获注入 | MockAiProvider |
| 技能(skill) | 可启用的能力包(`enabledSkills` 传入,取**应用激活技能**(如 report-style);注意与 agentType(场景代理,如 report-writer/knowledge-qa)是两回事,传非法值 500 | AiAgentRegistry |
| IA 指标系列 | `/actuator/prometheus` 的业务指标(`fusion_agentscope_runtime_*`、`ia_reconnect_total{app,result}` 等) | IaBusinessMetrics |
