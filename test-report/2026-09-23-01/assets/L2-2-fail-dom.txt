InnerAgent 接入总览

按《docs/接入指南.md》串起 开通登记 → 引依赖配桥 → 写工具 → 签发 embed token → 嵌入/工具调用 全链路

① 开通登记(平台方)
✓

管理面注册应用并登记宿主 RSA 公钥(signKeyFingerprint 核对),工具经 /ia-mcp 周期性被感知

② 引依赖 + 桥配置
✓

starter 自动装配 /ia-mcp 桥与 X-IA-Act 验签;act.audiences 必须与管理面 endpointUrl 一致

③ 写宿主工具 @IaTool
✓

宿主业务能力(建单/查单)以注解暴露;WRITE 先确认,READ 自动执行

④ 签发 embed token
✓

宿主私钥签 RS256(iss=appKey、sub=数字用户 ID、exp 12h、无 aud),公钥登记给 InnerAgent

⑤ 嵌入与调用
✓

WC 直挂或 iframe postMessage(token 不入 URL);Webhook HMAC 验签接收运行终态
