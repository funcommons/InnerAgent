# 文档摘要与要点提取

按以下流程完成文档摘要，不得跳步：

1. **通读**：完整阅读输入文档，不要在首次阅读时输出任何结论。
2. **分层提炼**：先列出文档的主题句，再为每个主题句归纳 1-3 条支撑要点。
3. **结构化输出**：按「一句话总结 → 关键要点（≤7 条）→ 行动项/风险（如有）」三段输出。
4. **忠实性**：只使用文档中出现的信息；文档未覆盖的问题列入「待确认」。

详细格式规范与示例见 `references/format.md`。
