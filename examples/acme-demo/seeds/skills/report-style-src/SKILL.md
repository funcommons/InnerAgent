# ACME 报告写作规范(report-style v1.0.0)

本 Skill 激活后,你撰写的任何 ACME 业务报告(周报、月报、项目复盘、专题分析)
必须遵循以下规范;与用户显式要求冲突时,先指出冲突并请求确认。

## 一、结构要求

1. 报告一律采用「结论先行」结构,第一段为不超过 3 句话的执行摘要;
2. 正文按「背景与口径 → 关键数据 → 分析与归因 → 风险与依赖 → 下一步动作」组织,
   小节可按需裁剪,但「关键数据」与「下一步动作」不可省略;
3. 「下一步动作」每条必须带责任人与时间点(格式:动作 — 负责人 — 截止日);
4. 全文使用 Markdown,一级标题为报告名,数据一律用表格呈现,不使用截图占位。

结构骨架与措辞模板见 references/outline.md,动笔前先对照该模板搭好框架。

## 二、语气与用词

- 中文书面语,短句优先;一段只说一件事,段落不超过 6 行;
- 归因表述区分事实与推断:事实用「数据显示」,推断用「初步判断」,禁止混用;
- 风险表述必须带影响面与概率(高/中/低),不允许「可能有一定风险」这类模糊句;
- 对内报告直接点名问题;对外(客户/合作方)版本删去人名,改用角色指代。

## 三、数字与单位表述

- 金额单位统一为「万元」,保留一位小数;表格首行注明单位;
- 环比、同比必须注明口径与基期(如「环比 2026-08,同比 2025-09」);
- 百分比保留一位小数;涨跌用「+/-」前缀,不用「上升了大约」;
- 一切数字必须可溯源:来自宿主工具的标注工具名,来自用户输入的标注「(用户提供)」。

## 四、禁用清单

- 禁用口语词:「挺好的」「蛮多」「巨量」;
- 禁用绝对化表述:「必然」「肯定」「百分之百」;
- 禁用无出处的数字:凡未标注来源的数据一律不得写入报告;
- 禁用情绪化措辞与对具体个人的评价,复盘对事不对人。
