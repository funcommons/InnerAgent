# 参考 · 02 限制与配额

> 数值口径与仓内代码/测试同源;标注「默认」的通常可用配置覆盖,变更以平台侧公告为准。

## 配额

| 项 | 值 | 说明 |
| --- | --- | --- |
| 每用户三方 MCP 注册数 | ≤ **32**(超限拒绝 400,按活跃行计数) | 用户级自助;应用级(管理面)不限此数 | 
| serverKey 字符集 | `[a-zA-Z0-9-]`,1-64 字符 | 冲突域=应用级表/宿主注册表/用户级表任一占用即 409 |
| 三方 MCP 注册超时 | `timeoutSeconds` 默认 **30s**(1-600) | 登记字段,按端点特性调整 |
| 模型并发登记 | `max_concurrency` 默认 **5** | 登记字段;压测/大流量环境按供应商限流校准(压测口径 1000) |

## 超时

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 工具确认超时 | **24h** | 超时自动过期(`POST /runs/{runId}/confirm/expire` 可主动收口);生产建议按业务收紧 |
| 运行超时 | **30m** | 平台侧 run-timeout;压测客户端按 30s 口径自保(`IA_RUN_TIMEOUT_MS`) |
| act token 有效期 | **60s** | 平台回调宿主桥的一次性内环凭证 |
| embed token TTL | **43200s(12h)** | `IA_EMBED_TTL_SECONDS` 可调;**生产建议 ≤30min** 由宿主续签 |
| SSE keep-alive | **30s/条** | 注释帧,客户端解析方忽略;死连接 ~2 个间隔内被暴露释放 |

## 事件与吞吐(实测口径,2026-09-28 容量报告)

| 项 | 值 |
| --- | --- |
| 事件 journal | ≈11 条/运行;SSE 投影纯回复 3 条 / 工具流 6 条每运行 |
| 库容量 | ≈18KB/运行 → **生产必须配 journal 归档/分区** |
| 单实例并发(本机 15 核共存形态已证) | 100 并发 × 30min 零失败 ×2 形态;1000 空闲会话驻留 |
| outbox 消化 | ~400 行/s 设计点(批量化后;更高吞吐调 `outbox-delay-ms`/BATCH_SIZE) |
| 透传/首字门槛 | 验收口径 透传 P95 ≤200ms、首字 P95 ≤3s —— **专机部署复测定稿**(单机共存形态数据见容量报告) |

## 行为限制

| 项 | 说明 |
| --- | --- |
| `toolExecutionMode` 豁免档 | `ALWAYS_ALLOW`/`FULL_ACCESS` 须请求体显式声明;不要作为业务助手默认 |
| 三方 MCP OAUTH | 枚举预留位,配置即 **501**(CIMD 流程后续批次) |
| 子 Agent 护栏 | 深度/并发护栏触发 **429**(唯一已知 429 源) |
| 行级隔离语义 | 越权访问一律 **404**(不泄露存在性),不是 403 |
| MCP 传输 | 仅 `streamable-http` + `STATIC_HEADER` |
| mock 模型 | 严禁生产设为默认(恢复脚本 `seeds/mock-model-restore.sql`);规则必须挂 `config.mockScript` 键下 |
