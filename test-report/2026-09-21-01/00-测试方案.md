## 3. 本轮用例设计要点

- 每线正常流 + 异常流;通过 = 关键步骤截图/网络响应落文件;失败 = trace + 全步截图 + console 落文件(playwright 配置 retain-on-failure)。
- 用例可复跑:固定标识符 + 每用例自建前置(查库判定,缺则补建)+ 物理清理自建数据。
  - 背景:Playwright 1.63 在用例失败后会以**新模块实例**继续(worker salvage),模块级随机常量跨用例不可信(有探针实验证实,见 R1 分册附录)。
- 数据佐证:授权/审计行经 psql 直查;检索面合成数据直插 `ia_audit_log`(写路径归 T2 SDK 线),借服务端「读时脱敏」设计验证出参防线。
- 约束:全程零产品代码改动;缺陷只记录定级(见 R1 分册缺陷清单),修复交后续独立 agent。
