## DEF-01(web 登录页契约漂移)· P1

- **现象**:web 登录页(`web/src/views/LoginView.vue` + `stores/auth.ts` + `api/auth.ts`)仍实现早期占位契约:请求体 `{adminKey}`,服务端 `LoginReqVO(username,password)` `@NotBlank` → 400。真服务模式下 **UI 无法登录**,管理站不可用(仅自动化 key 通道可用)。
- **证据**:`assets/L1-09-DEF01-UI登录400错误态.png`(错误态)、`L1-08-DEF01-UI登录-网络响应.json`(HTTP 400,code=400,msg=不能为空)。
- **修复意见**:
  1. `api/auth.ts` login 改发 `{username, password}`;`stores/auth.ts` 存 `token/expiresInSeconds`,请求层注入 `Authorization: Bearer`(AdminTokenFilter 已支持 Bearer 通道,`X-IA-Admin-Key` 自动化通道保留);
  2. LoginView 增加「用户名/密码」两个字段(替换管理 Key 单域),错误文案区分 401(凭据错误)与 423(锁定,透出剩余秒数);
  3. 会话过期处理:401 → 清登录态跳登录(`setUnauthorizedHandler` 已具备);
  4. 同步清理 `api/auth.ts` 与 `types.ts` 头部过时注释(「服务端无 /admin/auth 端点」已不成立)。
- 附注(不计缺陷):服务端未配 `IA_ADMIN_SESSION_SECRET` 时会话密钥进程内随机,重启即全体会话失效(server.log WARN 有提示),生产部署需注入持久化密钥。
