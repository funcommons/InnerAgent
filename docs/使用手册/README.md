## InnerAgent 是什么(30 秒)

InnerAgent 是一个**多租户 Agent 中台**:你的应用(宿主)把 AI 助手能力整体外包给它——
它负责 Agent 编排、模型调度、工具调用与**授权确认流**、会话/消息持久化、SSE 事件流推送、
观测大盘;你的应用只需**注册自己的业务工具、签发用户身份 token、挂一个前端聊天组件**。

三个角色:

```
┌─────────────┐    签发 embed token / 注册工具     ┌──────────────────┐
│  平台方      │◄──────────────────────────────────│   接入方(你)     │
│ (运营本平台) │    RS256 私钥不出宿主后端           │  宿主前端+后端    │
└─────────────┘                                    └────────┬─────────┘
      │  POST /ia/api/v1/runs (SSE)                         │ <inneragent-chat>
      ▼                                                     ▼
┌────────────────────────────────┐              ┌──────────────────┐
│  InnerAgent server(:18090)     │──工具桥 MCP──▶│  宿主 /ia-mcp    │
│  编排·模型·工具授权·事件流·持久化 │◀──────────────│  (你的业务工具)  │
└────────────────────────────────┘   X-IA-Act   └──────────────────┘
```

## 全局速查

| 项 | 值 |
| --- | --- |
| server API 基址 | `http://localhost:18090/ia/api/v1`(SSE:POST `/runs`) |
| 网关(带前端静态) | `http://localhost:18081`(`/ia` 反代 18090) |
| 管理面鉴权 | 请求头 `X-IA-Admin-Key` |
| 宿主身份 | embed token(RS256,`Authorization: Bearer`);act token `X-IA-Act`(60s 内环) |
| 观测 | `GET /actuator/prometheus`、`GET /actuator/health` |
| 参考实现 | `examples/acme-demo/`(宿主前后端完整接入) |
