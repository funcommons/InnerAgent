## 执行纪律(用户指令,逐条遵守)

1. 主 agent 只做分工调度与汇报;子 agent 做执行;**并发 ≤5**;
2. 每步代码 ≤1000 行;多步推进;
3. 每步循环:**子agent写测试 → 子agent写业务代码 → 子agent跑测试 → 修复**,
   直到 4 轮或无 P0~P2 级建议(优化建议→执行建议)为止;
4. 单元测试只测对应代码,不做全量;测试**编写**与测试**执行**是不同子 agent 任务;
5. 累计改动 >10% 或 >1000 行或 >10 个任务 → 子 agent 跑全量测试(不阻塞编码);
6. 每个子 agent 任务只做一件事:写文档 / 写业务代码 / 做测试 / 其它;
7. 测试不阻塞写代码:跑测试期间主 agent 继续调度后续编码任务。
