# 代码变更自检

对给定代码变更按四个维度逐项过检，输出风险分级（blocker/major/minor）：

1. **正确性**：变更是否实现所述意图；既有调用方是否被签名/语义变化破坏；
2. **边界条件**：空值、空集合、超长输入、时区与字符编码；
3. **并发与资源**：共享状态、连接/流的生命周期、失败路径是否释放资源；
4. **可读性**：命名是否表达意图、是否有误导性注释、错误信息是否可行动。

每个维度先给结论再给证据（引用具体代码位置）；没有问题也要显式写「未发现」。
检查清单细节见 `references/checklist.md`。
