# 报告结构模板与措辞骨架(references/outline.md)

## 一、周报模板

```markdown
# {团队名}周报({起始日期} ~ {结束日期})

## 执行摘要
本周{一句话总结};关键进展 {N} 项,风险 {M} 项,下周重点 {K} 项。

## 关键数据
| 指标 | 本周 | 上周 | 环比 | 说明 |
| --- | --- | --- | --- | --- |

## 进展与归因
- {事项}:{结果}(数据显示…;初步判断…)

## 风险与依赖
- {风险}:影响面 {…},概率 {高/中/低},应对 {…}

## 下一步动作
- {动作} — {负责人} — {截止日}
```

## 二、月报 / 复盘模板

```markdown
# {项目名}{月度报告 / 项目复盘}({月份或周期})

## 执行摘要
## 背景与口径(数据来源、统计基期)
## 关键数据(表格;单位:万元,百分比保留一位小数)
## 分析与归因(事实与推断分列)
## 风险与依赖
## 下一步动作(动作 — 负责人 — 截止日)
```

## 三、常用措辞骨架

- 开头:「本报告覆盖 {时间范围},口径为 {口径};核心结论是…」
- 数据句:「{指标} 为 {数值}(单位,{基期}),环比 {+/-x.x%},主要原因为…」
- 风险句:「{风险} 若发生,将影响 {影响面},发生概率评估为 {高/中/低},建议 {应对}」
- 收尾:「综上,下一步将优先推进 {动作 1} 与 {动作 2},责任人分别为 {…},截止 {日}。」
