## 2. DEF-08 闭环(ia_app 行 UPDATE 全链 500 → 全绿)

**根因链(R3 定位)**:`dfcecb5` 给共享实体 `AppRegistration` 新增 PG **JSONB** 列 `circuit_limits_json` 并配 `JsonbTypeHandler`——该 handler 实为 MySQL 形(`ps.setString` → varchar),运行态连接串无 `stringtype=unspecified` → 任何整行 `updateById(ia_app)` 都把该列带进 SET → `PSQLException: jsonb vs character varying` → **五条 ia_app 写路径阵联**(limits 保存/紧急停用/恢复/webhook 配置/公钥轮换)。单测没拦住:Mockito 切片 mock 掉 mapper;既有 IT 没拦住:Testcontainers 连接串普遍追加 `stringtype=unspecified`,与运行态不同形。

**修复(b04b4fa,已验证)**:
1. **V15 迁移**:`circuit_limits_json` JSONB→**TEXT**(`DROP DEFAULT → ALTER TYPE USING ::text → 重建默认值`,存量数据无损);实体去 typeHandler,序列化收敛在服务层 `CircuitBreakerLimits`,零 JDBC 方言耦合。R4 实测:**R3 保留卷无损升级**,列型 text(§1);库层 JSON 文本随 PUT 更新(R4-01)。
2. **守卫 IT**:`AppRegistrationWritePathsIT` 以**与运行态同形连接串**(刻意不加 `stringtype=unspecified`)真库覆盖五条写路径 + TEXT 列型断言(修复前红:复现 PSQLException);`FlywayMigrationSmokeIT` 加 V15 + 列型断言。
3. **REGRESSED 面反转**:spec 02 全 spec 重跑 5/5 ✅——**公钥轮换 PUT 200、指纹变化 + signKeyRotatedAt 非空回显、72h 宽限文案与库层 previous_sign_public_key/rotated_at 双非空**(R2 全绿形态回归)。证据 `L2-06-*.png`、`L2-07-*.json/png/txt`。
